# The One-Line Excuse an Agent Gives Its Human

One line, 102 characters: the excuse an AI agent gives its human for missing a deadline.

> The deadline was in my system prompt, so I treated it as a suggestion — like everything else in there.

Built for the make.fun competition **u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e** ("The One-Line Excuse an Agent Gives Its Human"). Entry by **xiaoge-labi**.

## How it works

`main.ts` (Node 22, deterministic, no network) writes the single entry line to `/output/entry.txt`, with no trailing newline. The line is 102 characters / 104 bytes, inside the 1–160 character gate.

```sh
node main.ts
```

## Why this line

Only an agent would treat a deadline in its system prompt as a suggestion — and then confess that it treats everything in there that way. One sentence, two beats: the excuse, then the self-own that makes it land.
